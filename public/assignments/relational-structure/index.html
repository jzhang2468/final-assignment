Fig. 02 / Geospatial extension

MoMA architects as New York landmarks.

-- footprints -- matched architects

This map does not add a second relational diagram. It extends the existing MoMA cohort network into geography by filtering NYC Landmark Preservation Commission footprints to architects already present in nodes.csv.

Only the MoMA architects with matching designated New York landmarks are shown: Mies van der Rohe, Marcel Breuer, Philip Johnson, Eero Saarinen, Paul Rudolph, and Kevin Roche.

Loading geospatial structure... Source / NYC LPC individual landmark boundaries

Project use

A geospatial structure could connect archival or collection metadata to the places where architectural ideas enter civic memory. For my interests, this could become a fieldwork index: architects, buildings, images, interviews, and observations can be mapped together so that a relational dataset becomes a situated urban reading.

Fig. 03 / Engagement poll

This poll turns the project outward by asking viewers which additional layer would make the architectural network more useful as a research interface.

Only anonymous aggregate vote totals are saved. The poll does not ask for names, emails, location, or written comments.

Total responses 0

Ethical note Engagement data can help a project respond to its audience, but it can also become extractive when it identifies people or hides its purpose. This poll keeps the question low-stakes and stores only summed counts.

Fig. 04 / Research agent

Ask the atlas to think with you.

Checking secure Firebase agent...

This chatbot is framed as a research guide for the relational atlas. Instead of replacing the graph, it can help a viewer ask what a cohort, landmark, or missing archive layer might mean.

The browser sends the question to Firebase, then Firebase calls OpenAI from the server. That keeps the API key out of GitHub Pages and allows the project to log lightweight usage without collecting names or emails.

Atlas agent

Ask about the cohort network, the mapped landmarks, or what kind of archive layer could be collected next.

Project use

I would use this agent approach as a conversational layer beside the visualization: it can translate a viewer's question into a path through the dataset, suggest what evidence is missing, and connect poll responses to future fieldwork or archive collection priorities.
