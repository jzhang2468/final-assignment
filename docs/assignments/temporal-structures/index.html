A fictional timeline of overlapping design, ecology, infrastructure, and public programs.

This single D3 visualization adapts the class Gantt-style timeline example by changing the CSV file to a synthetic dataset. Each band marks the duration of one fictional project phase, making it possible to compare which temporal layers happen in parallel and which depend on earlier groundwork.

Temporal Structure Reflection

In my precedent study of Excavating AI, I could incorporate a temporal structure by mapping the historical layers behind machine vision: early experiments, dataset collection, taxonomic systems, human labeling labor, benchmark culture, and later public critique. Instead of presenting AI as a single finished technology, the timeline would show how each stage leaves traces in the next, making bias visible as something accumulated over time through repeated acts of classification.
